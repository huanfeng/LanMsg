# LanMsg 桌面端视觉规范（v1）

适用：`crates/lanmsg-desktop` 所有视图。实现只用 windui 现有能力（`Theme`/`Palette`/`Metrics`、`Style`、`icon_svg`）；
某条规范 windui 做不到时，在任务报告里写明“缺能力：xxx”，不要为此改 windui，也不要硬凑近似效果。

## 1. 定位

LanMsg 是“自己的几台设备之间”的聊天式传输工具。界面的个性来自**设备与在线状态**，而不是装饰：
谁在线、消息来自哪台设备、文件在哪台设备上——这些信息要一眼可读。其余一切保持安静：
中性底色、少量层级、没有渐变、没有阴影堆叠。

唯一允许“醒目”的元素：**在线状态与强调色**（选中会话、未读、主按钮、我发出的消息气泡）。

## 2. 色彩（浅色主题；暗色主题按 4 节推导）

| 名称 | 值 | 用途 |
|---|---|---|
| `ink` | `#16202A` | 正文、标题 |
| `ink_muted` | `#4F5C68` | 次要文字（预览、说明） |
| `ink_subtle` | `#5F6C78` | 时间戳、脚注 |
| `canvas` | `#F4F6F7` | 窗口背景、内容区背景 |
| `rail` | `#E9EDEF` | 左侧图标栏背景（与列表区分层） |
| `surface` | `#FFFFFF` | 会话列表、卡片、输入框、对方气泡 |
| `line` | `#DCE2E6` | 分隔线、输入框描边 |
| `signal` | `#0B7A75` | 强调色（深青）：选中、主按钮、未读徽章底、我的气泡 |
| `signal_soft` | `#E8F4F2` | 选中行底色、次要强调底 |
| `online` | `#1E9E5A` | 在线点 |
| `danger` | `#C2410C` | 错误、校验提示 |

做法：在 `main.rs` 构造一个基于 windui 浅色主题的 `Theme`，把上表映射到 `Palette`（`accent=signal`、`bg=canvas`、
`surface=surface`、`text=ink`、`text_muted=ink_muted`、`text_subtle=ink_subtle`、`border/divider=line`），
`rail`、`signal_soft`、`online`、`danger` 放在 `crates/lanmsg-desktop/src/style.rs` 的常量里。视图里**不得**再出现其他色值字面量。

头像底色只用这 6 个（同明度、低饱和，白字对比 ≥ 4.5:1），按会话/用户 id 哈希取：
`#3D6E8F` `#5B6E3A` `#7A5A8C` `#8C5A3D` `#3D7A6E` `#6B6478`。

## 3. 字体与字号

系统字体（Windows：Microsoft YaHei UI / Segoe UI；Linux：Noto Sans CJK SC；由 windui 默认决定，不内嵌字体）。

| 档位 | 字号 | 字重 | 用途 |
|---|---|---|---|
| title | 20 | 600 | 页面标题、向导标题 |
| heading | 15 | 600 | 会话标题（聊天区顶栏）、分组标题 |
| body | 14 | 400 | 正文、消息文字、列表标题（未读时 600） |
| meta | 12 | 400 | 预览、说明、时间戳、徽章 |

- 不用全大写，不在内容上方加“标签式小标题”，不用 `A · B · C` 拼接元信息。
- 列表行标题单行省略；消息正文最大行宽约 560px（约 40 个汉字），超出换行。

## 4. 暗色主题

跟随系统（`App::on_system_theme_changed`）。映射：`canvas #12181D`、`rail #182027`、`surface #1C252C`、`line #2B363F`、
`ink #E6ECEF`、`ink_muted #A3B0BA`、`ink_subtle #8D9AA5`、`signal #3FB8AF`（暗底上作文字/描边也够亮）、`signal_soft #1E3533`、
`online #3CC27A`、`danger #F08A5D`。头像底色不变。

## 5. 间距与形状

- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24。
- 圆角分层级，**不是一个值用到底**：输入框与按钮 6；卡片/对话框 10；消息气泡 12（靠自己一侧的下角 4）；头像与在线点为圆；徽章为胶囊。
- 不用阴影；层级靠底色（`rail` < `canvas` < `surface`）和 1px `line`。

## 6. 布局

```
┌──────┬────────────────────┬───────────────────────────────────────┐
│ rail │ 会话列表 (surface)   │ 内容区 (canvas)                         │
│ 64px │ 280px，右侧 1px line │ 顶栏 56px：会话名 + 在线设备            │
│      │ 搜索框 36px          │ 消息流                                  │
│ 图标  │ 行高 64px            │ 输入区（surface，顶部 1px line）         │
│ +文字 │                      │                                        │
└──────┴────────────────────┴───────────────────────────────────────┘
```

- 左对齐为主；只有空状态和向导卡片居中。
- **图标栏**：64px 宽，`rail` 底色。每项是 20px SVG 线性图标 + 下方 12px 文字，项高 56px，项间 4px。
  选中项：图标与文字用 `signal`，背景为 `signal_soft` 圆角 8 的块（宽 48）。
  未读/请求数徽章是**叠在图标右上角**的小红点数字（`signal` 底白字，最小 16px 高），不另起一行。
  顶部放 28px 的应用标识（`signal` 圆角方块 + 白色对话气泡，与托盘图标同形）。
- **会话列表**：`surface` 底，与图标栏、内容区之间各 1px `line`。
  行：左右内边距 12，头像 40，头像与文字间距 12；第一行标题（body）+ 右侧时间（meta，`ink_subtle`），第二行预览（meta，`ink_muted`）+ 右侧未读徽章。
  未读时标题 600、徽章为 `signal` 实底白字；已读时无徽章。选中行 `signal_soft` 底；悬停行 `canvas` 底。
  搜索框：左侧 16px 放大镜图标，占位“搜索聊天记录”，左右与行内容对齐（12px）。
- **空状态**（未选会话、无会话、无文件……）：居中一个 48px 线性图标 + 一句说明 + 一个能直接行动的按钮或提示（例如“从左侧选择一个会话，或在“联系人”里添加设备”）。不写“暂无数据”。

## 7. 控件

- **主按钮**：`signal` 实底白字，高 36；**次按钮**：`surface` 底 + 1px `line` + `ink` 字；**文字按钮**：仅 `signal` 字。
  一个视图里最多一个主按钮。
- **禁用**：保留形状，透明度降到 45%；旁边或下方必须有一句说明为什么不可用（例如名字为空）。
- **输入框**：高 36，`surface` 底，1px `line`，聚焦时 1.5px `signal` 边；占位文字 `ink_subtle`；校验失败时边框与下方提示用 `danger`。
- **徽章**：胶囊，meta 字号，最小宽 = 高；数字超过 99 显示 `99+`。

## 8. 消息区（Task 12 起）

- 我发出的：右对齐，`signal` 底白字气泡；对方：左对齐，`surface` 底 + 1px `line`，`ink` 字。
- 气泡内边距 8×12；同一作者连续消息间距 4，换作者 12。
- “我的设备”会话里，气泡上方用 meta 字号标注来源设备名（`ink_muted`），因为作者都是自己。
- 时间分隔：间隔超过 5 分钟插一行居中 meta 时间（`ink_subtle`），不在每条消息上都显示时间。
- 文件卡片：`surface` 底圆角 10，左侧 32px 文件类型图标，名字（body，单行省略）+ 大小与状态（meta）；
  状态用文字 + 图标表达（“点击下载”“下载中 42% · 3.1 MB/s” 用进度条，不靠颜色单独表达）。图片缩略图最大 240×240，圆角 10。

## 9. 文案

- 动作按钮写清楚会发生什么：“发送”“下载”“添加为联系人”“确认配对”；结果提示与按钮同词：“已添加为联系人”。
- 错误说明原因与办法：“未连接后台服务，正在重试…”“名字需 1–32 个字符”。不道歉，不写“操作失败”。
- 所有文案在 `strings.rs`。

## 10. 当前截图的问题清单（Task 10/11 已交付部分，由“视觉打磨”任务修复）

1. 图标栏只有文字，没有图标，也没有应用标识；“联系人”的徽章另起一行，打乱了项的节奏 → 按 6 节改为图标 + 文字 + 角标。
2. 图标栏与会话列表同为白底、无分隔，两者粘在一起 → 图标栏用 `rail`，中间 1px `line`。
3. 选中态只有文字变色，选中会话行没有底色 → 加 `signal_soft` 选中块与选中行。
4. 未读徽章是浅蓝底蓝字，存在感太弱，且标题没有加粗 → 未读时 `signal` 实底白字 + 标题 600。
5. 头像底色饱和度高、彼此明度不一（深藏青、焦橙、亮蓝）→ 换 2 节的 6 色。
6. 强调色是 windui 默认蓝，与“局域网/设备”无关，也是最常见的默认值 → 换为 `signal` 深青。
7. 搜索框没有图标，与行内容的左边距不一致 → 加放大镜，统一 12px。
8. 空状态只有一句“选择一个会话开始聊天”→ 按 6 节加图标与可行动的说明。
9. 向导：标题字重太轻；两个按钮同等权重且都禁用、没有说明原因 → 标题 600；“这是我的第一台设备”为主按钮，“加入我已有的设备”为次按钮；名字为空时在名字框下用 meta 字号说明“填写名字后继续”。
10. 向导卡片在大面积灰底里显得悬空 → 卡片上方加应用标识（48px）与产品名，卡片宽 440、内边距 24。

## 11. 对比度要求（v1.1 补充）

所有文字与其底色的对比度 ≥ 4.5:1（12px 的 meta 字号同样适用），主按钮悬停态白字同样 ≥ 4.5:1。
v1 中 `ink_subtle`（#8A97A3）在 surface 上只有 2.98:1，已改为 #5F6C78；`ink_muted` 同步加深以保持层级；`signal_soft` 调浅以保证选中项上的 `signal` 文字 ≥ 4.6:1；暗色 `ink_subtle` 改为 #8D9AA5。
`style.rs` 中须有单元测试断言以下组合的对比度：ink/ink_muted/ink_subtle × surface/canvas/rail/signal_soft（浅暗两套）、白字 × 主按钮实底与悬停。
